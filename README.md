# Unity 第三人称动作战斗 Demo

个人学习与求职演示。玩法参考《绝区零》，使用 Unity C# 实现角色移动、普攻连段、闪避、受击恢复和敌人攻击。角色、动作、场景、界面和音频等游戏素材来源于网络，相关权利归原权利人。

## 打开项目

1. 点击 [下载项目 ZIP](https://github.com/MoHuia/Demo/archive/refs/heads/main.zip)，或在仓库主页选择 **Code → Download ZIP**。
2. 解压后，在 Unity Hub 中添加 `Demo-main` 目录。该目录下应直接包含 `Assets`、`Packages` 和 `ProjectSettings`。
3. 用 **Unity 2022.3.62f3** 打开项目，等待资源导入和 Package Manager 下载依赖。ZIP 已包含完整的动画文件，无需安装 Git 或 Git LFS。
4. 打开 `Assets/Scenes/TrainingGround.unity`，点 Play 进入训练场。`Assets/Scenes/SixthStreet.unity` 可单独打开体验场景。

键盘鼠标操作为 WASD 移动、鼠标调整视角、左 Shift 闪避、鼠标左键攻击。
